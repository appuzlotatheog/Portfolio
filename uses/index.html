Uses

A look at the hardware and software I use daily to build things on the web. It's a minimal but effective setup that keeps me productive.

Hardware

Desktop Rig

I run a custom-built machine powered by a Ryzen 3 3200G and 16GB RAM. Storage is handled by a snappy 512GB NVMe SSD. It's not a monster workstation, but it chews through code, containers, and web tasks without breaking a sweat.

Operating System

Arch Linux

I use Arch, btw. I appreciate the rolling release model, minimalism, and total control over the environment. It stays completely out of the way once dialed in.

Software & Tools

VS Code

My go-to editor for larger codebases. Stripped down of clutter and equipped with high-contrast neo-brutalist themes.

Claude Code

I leverage Claude Code for inline, AI-assisted development right in my terminal to iterate fast.

Antigravity

My preferred AI agent CLI. It runs background tasks, builds boilerplate files, edits configurations, and accelerates my entire workflow.

Terminal Setup

Terminal efficiency is everything. I pair my terminal emulator with a fully tricked-out setup designed for speed, low latency, and clear git context cues.
